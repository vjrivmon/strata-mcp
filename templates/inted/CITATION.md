# Citation & reference rules — INTED / IATED (EDULEARN, ICERI, INTED…)

IATED publishes from an MS Word template; in LaTeX we approximate it with
`article` + `\bibliographystyle{ieeetr}` (no `natbib` needed).

## In-text citations
- **Numeric**, square brackets, via `\cite{key}` → `[7]`; numbered **in order
  of first appearance** in the text.
- Multiple: `\cite{a,b}` → `[3], [5]`.
- Don't use author-year or `\citep`/`\citet`. Don't write `[7]` as a noun;
  "as shown by Smith et al. [7]" or "prior work [7] reports…".

## Reference list
- Auto-generated by BibTeX from `references.bib`; a single numbered list at the
  end, ordered by citation order (the `ieeetr` style does this).
- Entries are compact: authors (initials + surname), title in quotes, venue,
  year, pages; DOI optional but encouraged. arXiv → `@misc` with `eprint` +
  `archivePrefix = {arXiv}`.
- IATED expects an explicit **Keywords** line right after the abstract (3–7
  terms, comma-separated) — the skeleton has it.

## Pitfalls the citation-qa check looks for
- `\cite{key}` with no entry in `references.bib`.
- Entries in `references.bib` never cited.
- A reference to a paper not in the strata library (invented citation).
- Author-year text-style citations or `\citep`/`\citet`.
- Hand-numbered `[3]` markers / a hand-written reference list.
- Missing or empty Keywords line after the abstract.
