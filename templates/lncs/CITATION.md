# Citation & reference rules — Springer LNCS

**Document class:** `llncs` (Springer Lecture Notes in Computer Science).
**Bibliography style:** `splncs04` (`\bibliographystyle{splncs04}`).

## In-text citations
- **Numeric**, in square brackets, generated by `\cite{key}` → `[7]`.
- Multiple: `\cite{a,b,c}` → `[1,4,9]` (sorted, compressed to ranges).
- Do **not** type the numbers yourself and do **not** use `\citep`/`\citet`
  (those are `natbib`; LNCS does not use author-year).
- A citation is a reference, not a noun: write "the Transformer architecture
  [12]", not "[12] proposed…". If you need the authors in the sentence, name
  them: "Vaswani et al.\ [12]".

## Reference list
- Auto-generated by BibTeX from `references.bib` at `\bibliography{references}`.
- Numbered `[1] … [n]`, ordered **alphabetically by first author surname**
  (splncs04), not by citation order.
- Each entry: authors (Surname, F.M.), title, venue, volume/pages, year, and a
  DOI when available. Use `@inproceedings` / `@article` / `@book`; arXiv
  preprints → `@misc` with `eprint` + `archivePrefix = {arXiv}`.

## Pitfalls the citation-qa check looks for
- A `\cite{key}` whose `key` is not in `references.bib` (dangling citation).
- A `references.bib` entry that is never `\cite`d (drop it, or cite it).
- A reference to a paper that is not in the strata library (invented citation —
  not allowed).
- `\citep` / `\citet` / `[Author, 2024]` text-style citations (wrong system).
- Hand-numbered reference lists or hand-written `[3]` markers in the body.
- `\keywords` missing from the abstract block (LNCS requires 3–5).
