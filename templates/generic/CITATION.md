# Citation & reference rules — generic (article + natbib, author-year)

**Document class:** `article`. **Citations:** `natbib` (author-year).
**Bibliography style:** `plainnat` (swap for `abbrvnat` / `apalike` if you like).

## In-text citations
- **Author-year.** Two forms:
  - `\citep{key}` → `(Vaswani et al., 2017)` — parenthetical, end of clause.
  - `\citet{key}` → `Vaswani et al. (2017)` — the authors are the sentence subject.
- Multiple parenthetical: `\citep{a,b}` → `(Smith, 2020; Doe, 2022)`.
- Page/section: `\citep[p.~5]{key}` → `(Vaswani et al., 2017, p. 5)`.
- Plain `\cite{key}` also works (acts like `\citet`), but prefer the explicit
  `\citep` / `\citet` so the intent is clear.

## Reference list
- Auto-generated by BibTeX from `references.bib`; ordered **alphabetically by
  first author surname** (`plainnat`). Do not hand-edit it.
- Standard fields: authors, title, venue, year, volume/pages, DOI. arXiv
  preprints → `@misc` with `eprint` + `archivePrefix = {arXiv}`.

## Pitfalls the citation-qa check looks for
- A `\citep`/`\citet`/`\cite{key}` whose key is missing from `references.bib`.
- Entries in `references.bib` never cited.
- A reference to a paper not in the strata library (invented citation).
- Bare numeric `[3]` markers (this template is author-year, not numeric).
- A hand-written reference list instead of `\bibliography{references}`.
- `(Author 2017)` typed by hand instead of `\citep{author2017}`.
