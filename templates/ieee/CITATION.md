# Citation & reference rules — IEEE

**Document class:** `IEEEtran` (`[conference]` or `[journal]`).
**Bibliography style:** `IEEEtran` (`\bibliographystyle{IEEEtran}`), with the
`cite` package loaded for sorted/compressed numeric citations.

## In-text citations
- **Numeric**, square brackets, via `\cite{key}` → `[7]`.
- Multiple: `\cite{a,b,c}` → `[1], [4]–[6]` (the `cite` package sorts and
  compresses ranges automatically).
- Treat `[7]` as a reference label, not a word: "a CNN-based detector [7]", not
  "[7] proposed…". To foreground authors, name them: "Vaswani \emph{et al.}\ [7]".
- No author-year, no `\citep`/`\citet`.

## Reference list
- Auto-generated by BibTeX from `references.bib`.
- Numbered `[1] … [n]` in **order of first citation** in the text (this is the
  IEEE convention — unlike LNCS's alphabetical order).
- IEEE style abbreviates: first-initials + surname for authors; abbreviated
  conference/journal names ("Proc.", "Int. Conf.", "IEEE Trans."); include DOI
  when available. arXiv preprints → `@misc` with `eprint` + `archivePrefix`.

## Pitfalls the citation-qa check looks for
- `\cite{key}` with no matching entry in `references.bib`.
- Entries in `references.bib` never cited.
- A reference to a paper not in the strata library (invented citation).
- Author-year `[Author, 2024]` text or `\citep`/`\citet` (wrong system).
- Hand-numbered `[3]` markers or a hand-written reference list.
- `\begin{IEEEkeywords}` block missing or empty.
